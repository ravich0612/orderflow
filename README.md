# OrderFlow

OrderFlow is a Java Spring Boot backend project for learning and demonstrating modern backend development concepts including REST APIs, PostgreSQL, Spring Data JPA, Spring Security, validation, testing, and deployment practices.

## Tech Stack

- Java
- Spring Boot
- Maven
- Spring Web
- Spring Data JPA
- PostgreSQL / Supabase
- Spring Security
- Lombok
- Validation
